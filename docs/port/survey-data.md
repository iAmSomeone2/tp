| Multi-character constants (`'J3D2'`, `'n_all'`; approximate) | 4170 | 146 | Used as 32-bit tags. Compilers agree on the value (first char = most significant byte), which equals the big-endian file bytes only after the file word is byte-swapped. |
| Sub-word value punning (`*(u8*)&x`; plain byte-pointer arithmetic is not counted) | 4 | 4 | Reads one byte/half of a wider value; picks the other end on a little-endian CPU. |
